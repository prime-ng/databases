Empty States

The “blank slate” shown when there is nothing to display. Every empty state is centered and always offers a next action — a large tinted icon (accent, not fill), a title, a muted one-line message, and a CTA.

No data yet

First-run / zero-record screens. The single solid-filled primary CTA points at the obvious next step.

No students yet

Once you admit students to this class they’ll appear here with their roll number, section and fee status.

<div class="p-empty" role="region" aria-label="No students yet">
  <span class="p-empty__icon p-tint-primary" aria-hidden="true"><i class="bi bi-inbox"></i></span>
  <h3 class="p-empty__title">No students yet</h3>
  <p class="p-empty__message">Once you admit students they&rsquo;ll appear here…</p>
  <div class="p-empty__actions">
    <button class="btn btn-primary"><i class="bi bi-person-plus"></i> Add student</button>
  </div>
</div>
Usage: empty tables/lists, brand-new modules. The icon is decorative (aria-hidden="true") and the block is a labelled role="region". Keep exactly one solid primary CTA; make secondary actions ghost/outline. Prime helper: .p-empty with .p-tint-* on the icon chip.

No search results

A filtered/searched view with zero matches. The message echoes the query; the CTA clears filters rather than dead-ending the user.

No results for “Anjali 10-Z”

We couldn’t find any student matching your search and filters. Check the spelling or widen the class/section filter.

<div class="p-empty" role="region" aria-label="No search results">
  <span class="p-empty__icon p-tint-info" aria-hidden="true"><i class="bi bi-search"></i></span>
  <h3 class="p-empty__title">No results for &ldquo;Anjali 10-Z&rdquo;</h3>
  <p class="p-empty__message">Check the spelling or widen the filter.</p>
  <div class="p-empty__actions">
    <button class="btn btn-ghost btn-ghost-primary"><i class="bi bi-x-circle"></i> Clear filters</button>
  </div>
</div>
Usage: search / filter result panes. Echo the query text in the title so it’s clear what returned nothing. The CTA is a low-emphasis ghost button because “clear filters” is a recovery, not a primary goal.

Error state

Something failed to load. A danger-tinted icon signals trouble (paired with the word “wrong”), and the CTA lets the user retry.

Something went wrong

We couldn’t load the fee ledger for this class. This is usually temporary — please try again in a moment.

<div class="p-empty" role="alert" aria-label="Something went wrong">
  <span class="p-empty__icon p-tint-danger" aria-hidden="true"><i class="bi bi-exclamation-triangle"></i></span>
  <h3 class="p-empty__title">Something went wrong</h3>
  <p class="p-empty__message">We couldn&rsquo;t load the fee ledger…</p>
  <div class="p-empty__actions">
    <button class="btn btn-outline-danger"><i class="bi bi-arrow-clockwise"></i> Retry</button>
  </div>
</div>
Usage: failed fetch / server error panels. Use role="alert" so assistive tech announces it. The retry CTA is .btn-outline-danger (accent, not a solid danger fill) so it reads as recoverable rather than destructive.

Permission denied

The user is authenticated but not authorised for this screen. Explain plainly and offer a path to request access rather than a hard dead-end.

You don’t have access

The Accounting module is restricted to Finance and Admin roles. Ask an administrator to grant you access if you need it.

Back to dashboard 
<div class="p-empty" role="region" aria-label="Access denied">
  <span class="p-empty__icon p-tint-warning" aria-hidden="true"><i class="bi bi-shield-lock"></i></span>
  <h3 class="p-empty__title">You don&rsquo;t have access</h3>
  <p class="p-empty__message">This module is restricted to Finance and Admin roles.</p>
  <div class="p-empty__actions">
    <button class="btn btn-secondary"><i class="bi bi-send"></i> Request access</button>
  </div>
</div>
Usage: 403 / policy-blocked screens (maps to Laravel authorization gates). State the required role and give a constructive CTA. The icon carries the meaning together with the “don’t have access” text — never colour alone.

Compact variant (in-panel)

A tighter .p-empty--sm for empty table bodies, small cards, or dropdown result areas where the full-height blank slate would be too heavy.

You’re all caught up

No new notifications right now.

<div class="p-empty p-empty--sm" role="region" aria-label="No notifications">
  <span class="p-empty__icon p-tint-info" aria-hidden="true"><i class="bi bi-bell-slash"></i></span>
  <h3 class="p-empty__title">You&rsquo;re all caught up</h3>
  <p class="p-empty__message">No new notifications right now.</p>
</div>
Usage: nest inside a card or table body. .p-empty--sm shrinks the icon and padding. A CTA is optional here — a purely informational “caught up” state can omit it.
