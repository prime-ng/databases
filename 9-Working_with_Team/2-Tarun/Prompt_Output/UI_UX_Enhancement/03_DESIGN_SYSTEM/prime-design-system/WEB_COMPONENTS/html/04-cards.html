Cards

Surfaces that group related content. Prime cards accent, don’t fill — a white/surface panel with a colored left-border or a small tinted icon chip carries the meaning; the card body itself is never a saturated colour block.

Usage: dashboard KPI rows. Wrap them in a responsive grid (grid-template-columns:repeat(auto-fit,minmax(210px,1fr))). Swap the accent with --primary/--success/--warning/--danger/--info; the left-border and the icon chip re-tint from one modifier. Trend direction is signalled by an arrow icon + words, not colour alone. .p-stat-card is a Prime helper (from cards.css); the icon chip auto-tints from the card’s accent.

Info card (title + body + footer meta)

The everyday Bootstrap .card with a header title, body copy, and a footer holding meta + an action. Prime restyles the framework classes — soft border, subtle shadow, token radius.
