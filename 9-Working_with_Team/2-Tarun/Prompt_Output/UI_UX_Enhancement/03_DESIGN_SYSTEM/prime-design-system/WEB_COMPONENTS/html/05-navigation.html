Usage: The app header. navigation.css restyles Bootstrap .navbar (surface background, subtle bottom border, --p-shadow-sm) and .navbar-nav .nav-link so hover/.active read as a primary tint, not a solid fill. The icon-only bell uses .p-header-icon (44px square touch target) and carries an aria-label that includes the count — colour is never the only signal. The .navbar-toggler exposes aria-controls/aria-expanded. Dropdown and mobile collapse need the Bootstrap bundle JS (loaded below).

Breadcrumb

A shallow trail (2–3 levels plus Home) showing where the current page sits. Chevron separators, muted ancestors, a primary-weighted current page.

Usage: Place directly under the page title. navigation.css styles Bootstrap .breadcrumb flat (transparent background), replaces the default separator with a token-tinted chevron (›) via .breadcrumb-item + .breadcrumb-item::before, and gives the current .active item primary text weight. Always wrap in <nav aria-label="breadcrumb"> and mark the last crumb aria-current="page".
