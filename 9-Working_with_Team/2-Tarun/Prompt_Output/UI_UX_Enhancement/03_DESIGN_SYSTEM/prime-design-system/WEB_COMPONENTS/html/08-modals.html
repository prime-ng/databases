Modals

Bootstrap 5.3 dialogs restyled with Prime tokens — soft radius-lg corners, an lg shadow, and a subtle tinted accent header per intent. We accent, we don't fill: reserve solid colour for the accent bar + icon, keep the body neutral.

Confirmation modal

Neutral / primary intent. A short title, one-line message, and a two-button footer — Cancel (ghost) beside the single solid Confirm (primary).

Publish results?
Marks for Class 8 · Mathematics will become visible to 42 students and their parents. You can unpublish later.

Usage: the everyday "are you sure?" for reversible primary actions. Styles Bootstrap .modal/.modal-content/.modal-header/-body/-footer; Prime adds .p-modal-confirm (primary accent header) + .p-modal-confirm__icon. modal-dialog-centered vertically centres it; modal-sm keeps a confirm compact. Footer order is Cancel-then-Confirm with the solid button last (primary on the right).

Form modal

A neutral header with a couple of fields in the body. Use for quick create / edit flows without leaving the current page.

Usage: wrap .modal-body + .modal-footer in a <form> so Enter submits and the Save button is type="submit". Uses the neutral header (no accent) — reserve accent headers for destructive/informational dialogs. Long forms scroll inside .modal-body (max-height 70vh); add .p-modal-sticky-footer on .modal-content to pin the footer.

Delete confirmation (danger)

A danger-accent header (tinted bar + bi-exclamation-triangle), warning copy that names the exact item, and a Delete button that is the only solid fill — deliberately red so the destructive action is unmistakable.

Delete student record?
You are about to permanently delete Aarav Sharma (Class 9-B, Adm #GIS-20481). This removes attendance, marks and fee history and cannot be undone.

Usage: irreversible deletes. .p-modal-confirm--danger tints the header bar + icon red (accent, not a fully red modal). Always name the item and spell out what is lost; wire aria-describedby to the body. The danger fill is reserved for the confirm button so red = "the point of no return", never mere decoration.
