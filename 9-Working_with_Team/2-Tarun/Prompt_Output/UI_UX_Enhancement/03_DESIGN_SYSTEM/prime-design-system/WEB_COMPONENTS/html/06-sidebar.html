<script>
  // Toggle treeview parents; keep aria-expanded in sync.
  document.querySelectorAll('.sidebar-menu .nav-link[aria-controls]').forEach(function (btn) {
    btn.addEventListener('click', function () {
      var li = btn.closest('.nav-item');
      var open = li.classList.toggle('menu-open');
      btn.setAttribute('aria-expanded', open ? 'true' : 'false');
    });
  });
</script>
Usage: The main app rail. sidebar.css styles AdminLTE .sidebar-menu .nav-link (44px rows, icon + label), the .active item as a 3px left primary bar + primary tint + primary text (accent, don't fill), and rotates the .right caret when the parent <li> gains .menu-open. The treeview toggle is a real <button> with aria-expanded + aria-controls. Wrapping labels in <p> lets the mini rail hide them cleanly.

Mini / collapsed rail

On narrow desktops the rail collapses to an icons-only 64px strip; labels reappear as tooltips on hover. In the app, AdminLTE toggles .sidebar-collapse on the wrapper — here we show the end state statically.

Usage: Space-saving desktop mode. sidebar.css .sidebar-collapse rules hide .nav-link > p and centre the icons. Always keep aria-label + title on each item so the collapsed rail is still labelled for screen readers and hover tooltips.

Note — drawer pattern: The navbar hamburger (<button class="navbar-toggler">, see 05-navigation.html) toggles the drawer. When open: give the panel role="dialog" aria-modal="true", render a full-bleed .p-scrim beneath it, trap focus inside the drawer, move initial focus to the first item, close on Esc or a scrim tap, and restore focus to the hamburger on close. Respect prefers-reduced-motion by skipping the slide animation.
