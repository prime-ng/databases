Data Tables

Token-driven skins over Bootstrap .table: subtle tinted headers, soft row hover, sortable header buttons, a bulk-action toolbar, sticky headers, and a responsive card-stack for narrow screens. Icon actions always carry both aria-label and title.

Default table

Base .table inside a rounded .p-table-wrap frame. Header uses a subtle tint, rows a light divider.

    </thead>
    <tbody>
      <tr><td>ADM-0417</td><td>Aarav Sharma</td><td>Grade 6</td><td>A</td></tr>

Usage: Any read-only data grid. Wrap in .p-table-wrap for the rounded frame + horizontal scroll on small screens. Always mark header cells with scope="col".

Usage: The workhorse admin grid. Selecting rows toggles .is-active on .p-bulk-toolbar and updates the live count; the header checkbox selects all. Sort headers are real <button>s and set aria-sort on the <th> (ascending → descending → none). The status .form-switch gives each row a self-describing aria-label, and every icon action pairs aria-label with title so intent survives without colour. Filter chips + search narrow the visible rows.

Responsive card-stack

.p-table-stack turns each row into a card below 768px. Every <td> carries a data-label that is rendered as the field name via ::before. Switch the preview to Mobile (top-right) to see it stack.

Admission No.StudentClassStatusActions
ADM-0417 Aarav Sharma Grade 6 — A Active
ADM-0418 Diya Patel Grade 6 — B Inactive 
<table class="table table-hover p-table-stack">
  <thead><tr><th>Admission No.</th><th>Student</th><th>Class</th><th>Status</th><th>Actions</th></tr></thead>
  <tbody>
    <tr>
      <td data-label="Admission No.">ADM-0417</td>
      <td data-label="Student">Aarav Sharma</td>
      <td data-label="Class">Grade 6 — A</td>
      <td data-label="Status"><span class="p-tint-success">… Active</span></td>
      <td data-label="Actions">… icon buttons …</td>
    </tr>
  </tbody>
</table>

/* Below 768px each <tr> becomes a card and td[data-label]::before shows the label */
Usage: Any table that must survive a phone. On wide screens it renders as a normal grid; under 768px the <thead> hides and each cell prints its data-label as a field name via CSS ::before — no JS and no duplicated markup. The status pill uses tint + icon + text so meaning holds without colour.
