Dropdowns

Bootstrap 5.3 dropdowns restyled with Prime tokens — a floating surface panel (shadow-md, radius-lg), tinted hover (not filled), 40px rows and danger actions carrying colour plus icon plus label. Every toggle exposes aria-haspopup/aria-expanded and items are keyboard reachable.

Action (row) menu

The classic "kebab" (⋮) menu attached to a table row or card — View / Edit, a divider, then a danger Delete.

Usage: per-row / per-card actions in tables and lists. Styles Bootstrap .dropdown-menu/.dropdown-item/.dropdown-divider; Prime adds .p-menu-icon (muted leading glyph) and .p-menu-danger (red text + icon for destructive items). Use .dropdown-menu-end so a right-aligned kebab opens flush to the row edge. Icon-only toggles need an aria-label.

Filter menu

A "Filter" button opening a menu of checkable options with an Apply / Clear footer. Stays open while you tick boxes (data-bs-auto-close="outside").

    <i class="bi bi-funnel"></i> Filter <span class="badge text-bg-primary rounded-pill">2</span>

    </label></li>
    <!-- …more options… -->
    <li>
      <div class="p-menu-filter__foot">
        <button type="button" class="btn btn-ghost btn-sm">Clear</button>
        <button type="button" class="btn btn-primary btn-sm">Apply</button>
      </div>
    </li>
  </ul>
</div>
Usage: multi-select filtering on a list/report toolbar. data-bs-auto-close="outside" keeps the panel open while ticking boxes and closes only on an outside click. Wrapping each option in a <label class="dropdown-item dropdown-item-text"> makes the whole 40px row a click target. The .p-menu-filter modifier left-aligns rows; the count badge on the toggle reflects active filters.
