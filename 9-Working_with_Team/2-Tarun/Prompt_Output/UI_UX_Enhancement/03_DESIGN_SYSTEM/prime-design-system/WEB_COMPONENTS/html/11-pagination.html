Pagination

Splitting long result sets across pages. Styles Bootstrap's .pagination so the current page reads as a tinted, bordered accent chip — not a heavy solid fill — with 40px targets and visible focus rings.

Numbered pagination

The default for tables and grids. The active page is marked with both a tinted accent style and aria-current="page"; prev/next use chevron icons and carry an aria-label. The whole control lives in a labelled <nav>.

  • Prev
  • 1
  • 2
  • 3
  • …
  • 12
  • Next 
<nav aria-label="Student list pagination">
  <ul class="pagination">
    <li class="page-item disabled">
      <a class="page-link" href="#" aria-label="Previous" aria-disabled="true" tabindex="-1">
        <i class="bi bi-chevron-left"></i> <span>Prev</span></a>
    </li>
    <li class="page-item active"><a class="page-link" href="#" aria-current="page">1</a></li>
    <li class="page-item"><a class="page-link" href="#">2</a></li>
    <li class="page-item"><a class="page-link" href="#">3</a></li>
    <li class="page-item disabled"><span class="page-link" aria-hidden="true">…</span></li>
    <li class="page-item"><a class="page-link" href="#">12</a></li>
    <li class="page-item">
      <a class="page-link" href="#" aria-label="Next"><span>Next</span> <i class="bi bi-chevron-right"></i></a>
    </li>
  </ul>
</nav>
Usage: Styles Bootstrap .pagination/.page-item/.page-link with .active + .disabled. Always set aria-current="page" on the active link and label the <nav>. Matches Laravel's default paginator markup.

Simple prev / next

When exact page numbers don't matter — infinite-ish lists, wizards, detail record navigation. Pair the buttons with a plain-language range summary so users know where they are.

Showing 1–20 of 240
  • Prev
  • Next 
<nav class="p-pager-simple" aria-label="Results navigation">
  <span class="p-pager-summary">Showing <strong>1–20</strong> of <strong>240</strong></span>
  <ul class="pagination">
    <li class="page-item disabled">
      <a class="page-link" href="#" aria-label="Previous page" aria-disabled="true" tabindex="-1">
        <i class="bi bi-chevron-left"></i> Prev</a>
    </li>
    <li class="page-item">
      <a class="page-link" href="#" aria-label="Next page">Next <i class="bi bi-chevron-right"></i></a>
    </li>
  </ul>
</nav>
Usage: Prime helpers .p-pager-simple (space-between layout) + .p-pager-summary. The "Showing X–Y of Z" text is the accessible anchor when there are no numbered pages to convey position.

Load more

For feeds and cards where users append rather than jump — one centered outline button (accent, not fill) plus a remaining-count. On click, swap it into its loading state while the next batch fetches.

Showing 20 of 240 
<div class="p-load-more">
  <button type="button" class="btn btn-outline-primary" aria-live="polite">
    <i class="bi bi-arrow-clockwise"></i> Load more
  </button>
  <span class="p-pager-summary">Showing <strong>20</strong> of <strong>240</strong></span>
</div>

<!-- on click, show progress by reusing the button loading state -->
<script>
  btn.classList.add('is-loading');   // spinner from buttons.css
  btn.setAttribute('aria-busy', 'true');
  // …fetch next batch, then remove is-loading + update the count
</script>
Usage: Prime helper .p-load-more. The button uses the outline variant so it accents without competing with page actions; toggling .is-loading (from buttons.css, linked on this page) gives the spinner-on-click state.
