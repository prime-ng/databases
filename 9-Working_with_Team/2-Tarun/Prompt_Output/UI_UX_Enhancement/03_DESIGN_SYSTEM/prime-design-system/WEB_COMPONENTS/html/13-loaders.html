Loaders & Skeletons

Busy-state building blocks: an accessible border spinner for indeterminate waits, and shimmer skeletons that reserve the final layout so content doesn't jump when it arrives. All motion freezes to a calm pulse under prefers-reduced-motion.

Spinner

The .p-spinner uses the border technique — a quiet primary-tint track with a solid accent arc. Wrap it in role="status" and include a .visually-hidden "Loading" so screen readers announce the wait; the motion alone is never the only signal.

Loading… Loading… Loading… Loading… Loading… Loading results… 
<!-- sizes: .p-spinner-sm (16) / default (24) / .p-spinner-lg (40) -->
<span class="p-spinner" role="status" aria-label="Loading">
  <span class="visually-hidden">Loading…</span>
</span>

<!-- with a visible label, the aria-label is optional -->
<span class="p-text-secondary" style="display:inline-flex;align-items:center;gap:8px">
  <span class="p-spinner p-spinner-sm" role="status"><span class="visually-hidden">Loading…</span></span>
  Loading results…
</span>
Usage: Prime helper .p-spinner (+ .p-spinner-sm / .p-spinner-lg / .p-spinner-muted). For indeterminate waits only — if you know progress %, use a progress bar instead.

Skeleton — card

Mirror the real card's shape so the layout is stable when data lands. The container is aria-busy="true"; the shimmer blocks are aria-hidden so they're not read out one by one.

Loading card… 
<div class="p-skeleton-card" aria-busy="true" aria-live="polite">
  <span class="visually-hidden">Loading card…</span>
  <div class="p-skeleton p-skeleton-thumb" aria-hidden="true"></div>
  <div class="p-skeleton p-skeleton-title" aria-hidden="true"></div>
  <div class="p-skeleton p-skeleton-text" aria-hidden="true"></div>
  <div class="p-skeleton p-skeleton-text p-skeleton-w-90" aria-hidden="true"></div>
  <div class="p-skeleton p-skeleton-text p-skeleton-w-60" aria-hidden="true"></div>
  <div class="p-skeleton p-skeleton-btn" aria-hidden="true"></div>
</div>
Usage: Prime helpers .p-skeleton-card + .p-skeleton shape modifiers (-thumb / -title / -text / -btn) and width helpers (.p-skeleton-w-90/75/60/40). Match the block count to the real content so nothing shifts on load.

Skeleton — table rows

Placeholder rows for a data table while the first page loads. Keep the real <thead> visible so column context is immediate.

StudentClassRoll no.Status
Loading table rows… 
<table class="table" aria-busy="true">
  <thead><tr><th>Student</th><th>Class</th><th>Roll no.</th></tr></thead>
  <tbody>
    <tr>
      <td><div class="p-skeleton p-skeleton-text p-skeleton-w-75" aria-hidden="true"></div></td>
      <td><div class="p-skeleton p-skeleton-text p-skeleton-w-40" aria-hidden="true"></div></td>
      <td><div class="p-skeleton p-skeleton-text p-skeleton-w-40" aria-hidden="true"></div></td>
    </tr>
    <!-- repeat rows for the page size -->
  </tbody>
</table>
<span class="visually-hidden" role="status">Loading table rows…</span>
Usage: Reuses .p-skeleton inside a real Bootstrap .table. Render as many skeleton rows as your page size (10, 20…) so the table height matches the loaded state.

Skeleton — list items

Avatar + two lines per row — for notification feeds, student lists, chat, etc. The whole list is one aria-busy region.

Loading list… 
<div class="p-surface p-border p-rounded" aria-busy="true" aria-live="polite">
  <span class="visually-hidden" role="status">Loading list…</span>
  <div class="p-skeleton-row">
    <div class="p-skeleton p-skeleton-circle" aria-hidden="true"></div>
    <div class="p-skeleton-lines">
      <div class="p-skeleton p-skeleton-text p-skeleton-w-60" aria-hidden="true"></div>
      <div class="p-skeleton p-skeleton-text p-skeleton-w-90" aria-hidden="true"></div>
    </div>
  </div>
  <!-- repeat rows -->
</div>
Usage: Prime helper .p-skeleton-row (flex avatar + .p-skeleton-lines). Vary the width helpers between rows so the placeholder reads as natural, ragged text rather than a solid block.

Button loading

For a button-triggered action, don't add a separate spinner — put the button itself into its loading state. This reuses .btn.is-loading from buttons.css.

<!-- link buttons.css too, then reuse the button loading state -->
<button type="button" class="btn btn-primary is-loading" aria-busy="true">Saving…</button>
Usage: This page links a second stylesheet (../css/components/buttons.css) to pull in .btn.is-loading. Keep the action's context — a loading button — instead of covering the region with a standalone spinner.

Reduced motion

Everything above respects @media (prefers-reduced-motion: reduce): the spinner and skeleton shimmer stop and cross-fade to a slow opacity pulse instead, so the busy state is still conveyed without sliding/spinning motion.

Usage: Enable "Reduce motion" in your OS accessibility settings and reload — the spinner arc and skeleton sheen switch to a gentle p-pulse. No JS needed; it's pure CSS in loaders.css.
