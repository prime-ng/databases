P Prime Design System v1.0.0

Prime Design System

A reference component library on top of AdminLTE v4.0.0-beta3 (Bootstrap 5.3) for the Prime school-management ecosystem — the Laravel web app, the admin mobile app, and the student/parent/teacher mobile app. Open any gallery below to preview components in light & dark, copy the code, and read usage notes.

This is a reference specification — not applied to the live apps. See AI_IMPLEMENTATION_GUIDE.md for how to implement.
