### B. `prime_testing` — automated Dusk test runner (`testing_v3`)

**One-line summary:** the browser tests could not start on a developer PC, so all evening was spent fixing how the test runner finds the `prime_ai` project and launches the test server, plus making machine identity safe on shared databases.

- **What was broken:** the Dusk runner needed to know where `prime_ai` lives. It used a path baked in from another PC and silently fell back to a wrong default, so the test server never started (or started against the wrong project).
- **What was fixed (8 commits, `49cb28d9` → `6d45c496`):**
  1. **Project path resolution** now tries, in order: `MAIN_PROJECT_PATH` env → settings table → this machine's DB row → `prime_testing/.env` → sibling `prime_ai` folder. Each candidate is validated (must contain `artisan` + `Modules`) before use.
  2. **No more silent fallback:** if the project or `vendor/` is missing, it errors with a clear message instead of pretending to work.
  3. **Dev server** now launches PHP's built-in server directly with opcache off (one worker), and reports exit code / signal / output when it fails to start.
  4. **Machine identity is safe:** the seeder detects *this* PC's workstation user before wiping the machines table, refuses the old "default to D03" behaviour, and refuses to overwrite another PC's MAC. Live hardware model/serial/OS is seeded for the current PC only.
  5. **Machine check on a shared DB** now ignores other PCs' rows (matches on hostname or MAC) so one machine's row is not flagged for everyone.
  6. **UI cleanup:** removed a duplicated scroll-to-top button/script from two backend layouts.
- **Action for the team (important):** every developer PC must set two values in `prime_testing/.env` — `MAIN_PROJECT_PATH` (path to your own `prime_ai` clone) and `TEST_RUNNER_CURRENT_USER` (A01, D02, D03, T01 or T02). Then run `composer install` inside your `prime_ai` clone. Without these, the runner now stops with an error by design.
- **Not done yet:** the Dusk suite itself was not run end-to-end today, so we cannot yet say the tests pass — only that the runner now *starts* and fails loudly.
