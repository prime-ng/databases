# Complaint Actions — Requirements

## What It Does
Immutable audit trail for every state change on a complaint. Every create, status change, assignment, resolution, and delete generates an action record providing a complete timeline of the complaint lifecycle.

## Database Fields

| Field | Type | Conditions |
|---|---|---|
| `complaint_id` | BIGINT FK → `cmp_complaints` | Required. Parent complaint. |
| `action_type_id` | BIGINT FK → `sys_dropdowns` | Created / Assigned / StatusChange / Resolved / Deleted. |
| `performed_by_user_id` | BIGINT FK → `sys_users` | Nullable (NULL = system action). |
| `performed_by_role_id` | BIGINT FK → `sys_roles` | Role of the performer. |
| `assigned_to_user_id` | BIGINT FK → `sys_users` | Applicable for "Assigned" actions. |
| `assigned_to_role_id` | BIGINT FK → `sys_roles` | Applicable for "Assigned" actions. |
| `notes` | TEXT | Action details. |
| `is_private_note` | BOOLEAN | Whether this note is internal only. |

## How Actions Are Generated

| Action Type | Trigger | Details Logged |
|---|---|---|
| **Created** | Auto-logged when a complaint is submitted | Performer, timestamp, initial values |
| **StatusChange** | Logged when complaint status is updated | Old status → new status, performer |
| **Assigned** | Logged when assignment changes | Assigner, assignee (user + role), timestamp |
| **Resolved** | Logged when complaint is marked resolved | Resolver details, resolution summary, timestamp |
| **Deleted** | Logged on soft delete | Performer, timestamp |

## CRUD Operations
- Primarily read-only view of audit trail data
- Displayed in the "Complaint Actions" tab of the master view
- Actions are auto-generated by the system — no manual create/edit
- Soft delete and force delete available for administrative cleanup

## Permissions

| Operation | Permission Key |
|---|---|
| View actions tab | `tenant.complaint-action.viewAny` |
| View action details | `tenant.complaint-action.view` |
| Create action note | `tenant.complaint-action.create` |
| Update action | `tenant.complaint-action.update` |
| Delete action | `tenant.complaint-action.delete` |
| Restore action | `tenant.complaint-action.restore` |
| Force delete action | `tenant.complaint-action.forceDelete` |
