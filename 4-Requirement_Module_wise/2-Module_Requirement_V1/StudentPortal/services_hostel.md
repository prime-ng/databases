# Services — Hostel Tab Requirements

## 1. Functional Overview
A placeholder screen displaying hostel building details, room allocations, and warden contacts once the Hostel module is configured.

---

## 2. Directory Layout & Parameters

### A. Allocated Room Details
- Displays assigned building name, room number, room type (e.g. 2-seater, 4-seater), and bed number.

### B. Hostel Crew details
- Displays warden name, contact number, and office location.

### C. Hostel Rules
- Lists rules, dining timings, and emergency contacts.

---

## 3. Database References
- Renders placeholder information if the student has no active hostel allocation.
