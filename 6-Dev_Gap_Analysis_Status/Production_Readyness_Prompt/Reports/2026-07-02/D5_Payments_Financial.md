## Task-by-task summary

1. **Razorpay integration** — Initiation: `PaymentService::initiate` (`PaymentService.php:31-85`) creates the order server-side with `payment_capture=1` (`RazorpayGateway.php:36-43`). Client callback is verified **server-side** via HMAC (`RazorpayGateway.php:74-91`) — not blindly trusted — and webhooks are HMAC-verified on the raw body (`VerifyWebhookSignature.php:55-62`). **But** the callback verification is not bound to the stored order (GAP-D5-001), which defeats it.
2. **Idempotency / double payment** — Webhook table has a unique idempotency key (misdesigned: GAP-D5-012). Payment rows: no unique `gateway_payment_id`, no status-transition guard, guard-outside-transaction races (GAP-D5-002). Same fee **can** be double-credited under concurrency.
3. **Transactions** — Present around callback + recordPayment (`ParentFeePaymentController.php:109-123`, `FeeInvoiceService.php:51`, `FeeInvoiceController.php:264`, Billing `:52,158`, `RefundService.php:43`). Lacking: `PaymentService::initiate/markSuccess` (payment update + audit log not atomic, `PaymentService.php:37-79, 96-109`); `FeeInvoice::updatePayment` standalone in Student/Mobile portals is atomic-by-single-statement but ledger-incomplete (GAP-D5-005).
4. **Money types** — Clean: `decimal(12,2)` throughout, zero float/double money columns. Issues: PHP float casts in flow (`(float) $payment->amount`), truncating paise conversion (GAP-D5-011), `round(...,2)` used inconsistently.
5. **Audit trail** — Payment module: excellent append-only trail. Fee ledger: payment recording unlogged (GAP-D5-007). Billing: logged. No delete routes exist for FeeTransaction/Payment rows (only PaymentGateway has forceDelete, gated — `PaymentGatewayController.php:172-177`).
6. **Refund / reconciliation** — Code skeletons exist; neither is reachable or fed by real data (GAP-D5-008, GAP-D5-009).
7. **Concession/waiver authorization** — All gated by permissions, but concession grant+approve collapses into one `create` permission with self-approval (GAP-D5-013); scholarships are properly separated.
