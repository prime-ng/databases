# D8 — Deployment / Infrastructure / CI-CD Audit

**Project:** Prime-AI (`/Users/bkwork/Herd/prime_ai`)
**Date:** 2026-07-02 | **Auditor:** DevOps & Deployment Engineer (read-only)
**Builds on Phase-A facts:** APP_ENV=local / APP_DEBUG=true; 44 vs 74 env keys; QUEUE_CONNECTION=database vs Horizon; Telescope in require; no CI; no Docker; committed `.env-original` (DEPLOY-ENV-02) and `TENANT_ADMIN_CREDENTIALS.md`.

## Verdict

**NOT DEPLOYABLE.** The application cannot even complete `php artisan route:list` (fatal parse error in a core module controller), `config:cache` and `route:cache` would both break the app, there is zero CI/CD and zero infra definition, the queue architecture is internally contradictory (database driver hardcoded + Horizon requiring Redis + a `backup` queue nobody consumes), and live secrets are committed to git. Every deployment-critical caching step in a standard Laravel deploy script fails or corrupts behavior today.
