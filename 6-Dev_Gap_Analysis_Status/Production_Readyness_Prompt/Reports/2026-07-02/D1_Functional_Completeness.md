## Method (reproducible)
1. **Stub scan** — tokenizer-based scan of every `public function` in `app/Http/Controllers` per module; classified STUB (empty body / return-literal / abort(501) / not-implemented marker) vs THIN (view-only, no data) vs real. False positives (e.g. `respondToDocRequest` matching "todo") manually removed and noted.
2. **Route→controller census (all 45 modules)** — every `[Controller::class,'method']` and `'Controller@method'` reference in `Modules/*/routes/*.php` checked against actual method existence (module + cross-module + `app/` search; base `App\Http\Controllers\Controller` verified empty at `app/Http/Controllers/Controller.php:5-8`, so no trait/parent rescue).
3. **View census** — every literal `view('…')` in controllers resolved to a `.blade.php` on disk (module namespace + app fallback).
4. **FRD spot-checks** — Billing, Ptm, Hostel sampled ≥10 controller methods each against their FRD requirement lists.

**Census limits (state of sample):** module route files only — app-level `routes/web.php` (which carries Billing/Prime central routes) not census-counted, but Billing was manually spot-checked there. Dynamic view names (`view('x'.$var)`) not resolvable → marked ⚠️ UNVERIFIED where relevant.
