# Quest Activity Log — What & How (Non-Technical)

## What This Screen Does

The Activity Log screen is like a security camera recording. It captures every important thing a student does while taking a Quest — switching browser tabs, losing internet connection, resizing the window, and other actions that might suggest cheating or technical problems.

This screen does NOT let teachers create logs. The logging happens automatically on the student's computer during the Quest. This screen is only for **viewing and filtering** those recorded events.

---

## When This Screen Is Used

- **Checking suspicious behavior** — A teacher thinks a student scored too high and wants to see if they switched tabs to search for answers
- **Technical support** — A student says they lost connection during the Quest; the teacher checks for "Connection Lost" events
- **Post-exam review** — School administrators check activity logs for security purposes
- **Parent meetings** — To show evidence of student behavior during online tests

---

## What Information You See

For each recorded event, you see:

| What You See | What It Means |
|-------------|---------------|
| Date & Time | Exactly when the event happened |
| Event Type | What the student did (e.g., "Tab Switched", "Connection Lost") |
| Student Name | Which student did it |
| Quest Name | Which Quest they were working on |
| Extra Details | More info like what website they visited or what screen size they changed to |
| IP Address | The student's internet address at that time |
| Browser/Device | What browser and device they were using |

### Types of Events You Can See

- **Tab Switched** — Student moved away from the Quest tab to another tab
- **Window Resized** — Student changed their browser window size
- **Connection Lost** — Student's internet went down
- **Fullscreen Exited** — Student left fullscreen mode
- **Paste Detected** — Student pasted text into an answer box
- **Right Click Detected** — Student used the right-click menu

---

## Important Rules

### Rule 1: Only Quests, Not Other Tests
This screen only shows logs for Quest attempts. It does NOT show logs from Quizzes or Exams.

### Rule 2: View-Only — No Changes Allowed
You can only look at the logs. You cannot add, edit, or delete them. Logs are created automatically by the system when a student takes a Quest.

### Rule 3: You Can Filter What You See
You can narrow down the logs by:
- **Event Type** — Pick one type from a dropdown (e.g., only "Tab Switched")
- **Date Range** — Pick a start and end date
You can use both filters together.

### Rule 4: Logs Are Permanent
Once a log is created, it cannot be changed or removed. These are permanent records for investigation.

### Rule 5: Extra Information in Each Log
Some events include extra details. For example:
- A "Tab Switched" event might show the website address the student visited and how long they were away
- A "Connection Lost" event might show how long the connection was down
- A "Window Resized" event might show the old and new screen sizes

---

## How to Use This Screen

### Viewing Logs
1. Go to the Quests section and click the "Activity Log" tab
2. You will see the most recent events first (15 per page)
3. Each row shows: date & time, event type, student name, and Quest name
4. Click on a row to see the full details

### Filtering Logs
1. Pick an Event Type from the dropdown (e.g., "Tab Switched")
2. Optionally set a date range
3. Click Search
4. The list updates to show only matching events

### Investigating a Student
1. Find a "Tab Switched" event for a student
2. Click to see what website they visited
3. Check their test answers on the Paper Check screen to see if their performance looks suspicious

---

## Example

Mr. Verma notices that Priya scored 95% on the "Physics Challenge" Quest, which seems very high for her.

He opens the Activity Log tab and filters by:
- Event Type = "Tab Switched"
- Date = the day of the Quest

The system shows 12 "Tab Switched" events for Priya during her 45-minute test:
- 3 times she went to "google.com" (searching for answers)
- 2 times she opened "physics-formulas.pdf"
- 7 other times she switched tabs

Mr. Verma now has evidence to discuss with Priya. He can also check her answers on the Paper Check screen to see if they match what she searched for.
