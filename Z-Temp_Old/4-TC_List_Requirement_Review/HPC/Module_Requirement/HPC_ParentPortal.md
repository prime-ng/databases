# HPC Parent Portal – Complete Guide for Teachers and Parents

**Who can use this portal:** Parents and guardians of students. They do NOT need a username or password. They do NOT need to install any app. They do NOT need any technical knowledge. All they need is a special link that the teacher sends them.

**Which students it covers:** All grade bands – Foundation (Nursery to Class 3), Preparatory (Class 4 to Class 5), Middle (Class 6 to Class 10), and Secondary (Class 11 and Class 12). Any student whose Holistic Progress Card has parent-observation sections will have a parent portal entry.

**What this feature does:** The Parent Portal lets parents contribute their observations about their child directly into the Holistic Progress Card. The teacher sends a private link to the parent by email or text message. The parent clicks the link, fills in a simple form about their child at home, and submits it. No login, no app, no technical knowledge required.

**Why this exists:** A child's development happens both at school AND at home. The teacher sees the child at school – how they behave in class, how they interact with peers, how they perform on tests. The parent sees the child at home – how they study, how they behave with family, what their hobbies are, how they manage their time. By combining both views, the Holistic Progress Card gives a COMPLETE picture of the child's development. Neither the teacher nor the parent has the full picture alone.

## How the Parent Portal Works – A Complete Step-by-Step Walkthrough

Let us follow the journey of a parent link from creation to submission. We will use a real example throughout.

---

### Step 1: Teacher Generates a Parent Link

The teacher opens a student's card and clicks a button called **"Generate Parent Link"**.

**What happens behind the scenes – explained simply:**

1. The system creates a unique, private web address (URL) for THIS student's card. This URL is like a one-of-a-kind key. No two students get the same link.
2. Inside the URL, there is a secret "token". A token is a long random string of letters and numbers. It looks something like: `a7b3k9m2x5p8`. This token acts like a password that is built into the link. Anyone who has the link can access the form – that is why the teacher must share it carefully.
3. The link is set to automatically expire in **7 days**. After 7 days, the link stops working. Even if the parent has not filled the form yet, they cannot use the link after 7 days.
4. The teacher can copy this link and share it with the parent in several ways:
   - **By email:** The system has an automatic email option. The teacher clicks "Send Email" and the system sends an email with the link to the parent's email address on file.
   - **By print:** The teacher can print the link on a letter or a note that the student carries home.
   - **By text message:** The teacher can copy the link and paste it into a text message or WhatsApp message.
   - **By phone call:** The teacher can read the link out loud (though this is not common because the link is long).

**Real-world example:**
> Mr Singh is the class teacher of Class 5-A. He has finished filling Aarav Patel's Holistic Progress Card. He wants Aarav's parents to fill their observation form. He clicks "Generate Parent Link". The system creates a link: `https://sunshineschool.edu.in/hpc/parent/view?token=a7b3k9m2x5p8`. Mr Singh copies this link and pastes it into an email to Aarav's mother, Mrs Patel. He also prints the link on a small slip of paper and gives it to Aarav to take home.

**Important:** The teacher can generate only ONE valid link per student per card at a time. If the teacher generates a new link, the old link automatically stops working. This prevents multiple active links from floating around.

---

### Step 2: Parent Opens the Link

The parent receives the email or message from the school. They see the link and click on it. The link opens in their web browser (like Chrome, Safari, Firefox, or Edge) on any device – a smartphone, a tablet, a laptop, or a desktop computer. The form works on all devices.

**What the parent sees on the first screen (the Parent Dashboard):**

When the link opens, the parent sees a simple welcome screen. This screen is called the Parent Dashboard. It shows the following information:

| Element | What It Shows | Example |
|---|---|---|
| **Student's Name** | The child's full name, exactly as it appears in the school records. This confirms to the parent that this is the right link for their child. | "Aarav Patel" |
| **Class & Section** | The child's class and section. This gives additional confirmation. | "Class 5-A" |
| **Card Status** | Whether the parent's part is Pending (not started), In Progress (partially filled), or Completed (submitted). | "Pending – Please fill the observation form" |
| **Message from Teacher** | (Optional) Any instructions, notes, or personal message that the teacher wants to share with the parent. The teacher can type this when generating the link. | "Dear Mrs Patel, please take a few minutes to fill this form about Aarav's habits at home. Your inputs are valuable for a complete assessment." |
| **"Start" Button** | A big, clearly visible button labelled "Start" or "Fill Observation Form". The parent clicks this to begin. | [Start] |

**What the parent sees if the link has expired or is already used:**

| Scenario | What the Parent Sees | Can They Submit? |
|---|---|---|
| **Link is valid and never used** | The Parent Dashboard with the "Start" button. Everything looks normal. | Yes – they can fill and submit the form. |
| **Form has already been submitted** | A message saying: "This form has already been completed. Thank you for your submission." The "Start" button is not shown. | No – the form is locked. If the parent needs to make changes, they must ask the teacher to generate a new link. |
| **Link has expired (7 days have passed)** | A message saying: "This link has expired. Please contact the school for a new link." The "Start" button is not shown. | No – the link no longer works. The parent must ask the teacher for a fresh link. |

**Why does the link expire after 7 days?**
Security. If a parent's email gets hacked, or if someone else gets hold of the link (for example, the student shares it with friends), the window of vulnerability is limited to only 7 days. After that, the link becomes useless. This is a standard security practice for sensitive information.

### Step 3: Parent Fills the Observation Form

When the parent clicks the "Start" button, they see the observation form. The form contains questions about their child at home. These questions come from the school's template – specifically, the fields that are marked as "parent-owned" in Template Management.

**What the parent sees is DIFFERENT from what the teacher sees.** The parent can ONLY see parent-owned fields. They cannot see:
- Teacher's assessment fields and comments
- Student's self-assessment
- Peer reviews
- Any other confidential information

This is important for privacy. The parent only sees the parts that are relevant to them.

**What the parent typically fills in – section by section:**

#### Section 5: Parent Comments

This is a free-text box where the parent can write anything they want to share with the teacher. There is no limit on what they can write.

**Typical things parents write:**
- Appreciation and positive observations: "My child has become more confident this term. Thank you for the encouragement."
- Concerns: "I am worried about his performance in mathematics. He seems to be struggling with word problems."
- Life events: "We had a family bereavement last month, which may have affected her concentration."
- Requests: "Could you please help my child with reading comprehension? I notice he avoids reading at home."

**Example of a complete parent comment:**
> "Aarav has shown great improvement in his confidence this term. He used to be shy but now he participates in family conversations more actively. However, I am concerned about his mathematics performance. He seems to avoid practicing at home. Could you please suggest some ways I can help him improve? Also, thank you for the wonderful sports day event – he was very excited to participate."

### Step 4: Parent Submits the Form

When the parent has answered all the questions (or as many as they want), they scroll to the bottom of the form and click the **"Submit"** button.

**What happens after the parent clicks Submit:**

1. **The form is saved.** All the answers are stored in the school's database. The teacher can now see them.
2. **The form is locked.** The parent cannot go back and change their answers. The link no longer works for editing.
3. **A "Thank You" message appears.** The screen changes to show a friendly message: "Thank you for your submission. Your observations have been recorded and will be used to complete your child's Holistic Progress Card."
4. **The teacher is notified.** The system notifies the teacher that the parent has completed the form. The teacher can see this on the Activity Assessment dashboard.

**What if the parent clicks the link again after submitting?**
They see a message: "This form has already been completed. Thank you for your contribution." They cannot submit again or change their answers.

**What if the parent wants to change their answers after submitting?**
They need to contact the teacher. The teacher can generate a new link, which will allow the parent to fill the form again. However, the old submission will be replaced by the new one.

## Step 5: Teacher Monitors Parent Completion

After the teacher sends the parent link, they can monitor whether the parent has completed the form or not.

**Where the teacher sees this information:**

1. **On the Student List screen:** The "Card Status" column may show an indicator for the parent's part. For example, it might show "Parent: Pending", "Parent: Completed", or "Parent: Link Expired".

2. **On the Activity Assessment dashboard:** There is a clear section for each contributor. The parent section shows:
   - "Parent: Completed on [date]" – if the parent has submitted
   - "Parent: Not yet started" – if the parent has not clicked the link yet
   - "Parent: In Progress" – if the parent has started but not submitted
   - "Parent: Link Expired – Resend needed" – if 7 days have passed without submission

**What the teacher can do if a parent has not submitted:**

| Situation | What the Teacher Can Do |
|---|---|
| The parent has not started yet (Pending) | Wait a few days. Send a reminder email or message. |
| The parent started but did not submit (In Progress) | Send a gentle reminder. The parent may have forgotten to click Submit. |
| The link has expired (7 days passed) | Generate a NEW link. This automatically makes the old link invalid. Send the new link to the parent. |
| The parent says they never received the email | Check the email address on file. If it is wrong, update it in the school system. Generate a new link and send it. |
| The parent does not have an email address | Print the link on a letter and send it home with the student. Or send the link via SMS/WhatsApp. |

**Real-world example:**
> Mr Singh checks the Activity Assessment dashboard for Class 5-A. He sees that 18 out of 28 parents have completed their observation forms. 5 parents have not started yet. 3 parents' links have expired. 2 parents are in progress (started but not submitted). Mr Singh generates new links for the 3 parents whose links expired. He sends reminder emails to the 5 parents who have not started. He sends a gentle reminder to the 2 parents who are in progress. Within a week, all 28 parents have submitted.

## Important Rules to Remember

1. **No login required.** The parent does NOT need a username, password, or any account. The token (the random string in the link) is the only security. This is intentional – it makes it easy for parents who are not comfortable with computers.

2. **Link expires after 7 days.** The teacher can generate a new link if needed. The old link stops working as soon as the new one is created.

3. **Link cannot be reused after submission.** Once the parent submits, the form is final. If changes are needed, the teacher must generate a fresh link.

4. **Parents only see parent-owned fields.** They cannot see teacher notes, student self-assessments, grades, or peer reviews. Their view is limited to their own questions.

5. **Guardian email must be in the system.** The automatic email feature needs the parent's email address to be saved in the school's database. If the email is missing or wrong, the automatic email cannot be sent. The teacher must share the link manually (by printing it, texting it, etc.).

6. **One active link per student.** Only one parent link can be active at a time for a given student. Generating a new link invalidates the old one.

7. **The form works on all devices.** Parents can use a smartphone, tablet, laptop, or desktop computer. The form automatically adjusts to fit any screen size.

## Common Questions from Parents (FAQ)

**Q: I do not have an email address. Can I still fill the form?**
A: Yes. The teacher can print the link on a paper and give it to your child to bring home. You can type the link into a web browser on any device.

**Q: I do not have a computer or smartphone. How can I fill the form?**
A: You can ask the teacher to help you fill the form at the school. Many schools have computer labs where parents can come and fill the form.

**Q: I made a mistake after submitting. What do I do?**
A: Contact your child's class teacher. They can generate a new link for you. You can fill the form again with the correct information.

**Q: The link is not working. What should I do?**
A: The link may have expired (if more than 7 days have passed) or it may have already been used. Contact your child's teacher and ask for a new link.

**Q: Is my information private?**
A: Yes. Your responses are visible only to the school's teachers and authorised staff. They are stored securely in the school's database. Your information will not be shared publicly.

**Q: Can I see the rest of my child's card?**
A: No. The Parent Portal only shows the parent observation form. The teacher's assessments, grades, and other parts of the card are not visible to parents through this link. After the card is published, you may be able to view the full card through a separate published link.

## What the Teacher Sees After the Parent Submits

After the parent clicks Submit, the teacher can see the parent's responses in several places:

### On the Student List Screen

The Card Status column updates to reflect the parent's progress. You may see:
- **Parent: Pending** – The parent has not opened the link yet.
- **Parent: In Progress** – The parent opened the link but has not submitted yet.
- **Parent: Completed** – The parent has submitted the form.
- **Parent: Link Expired** – The 7-day window passed without submission.

### On the Activity Assessment Dashboard

The dashboard shows a detailed view:
- **Parent: Submitted on [date]** – with the exact date and time of submission.
- **Parent: Not yet started** – the parent has not clicked the link.
- **Parent: In Progress** – the parent is still filling the form.
- **Parent: Link Expired – Resend needed** – the teacher needs to generate a new link.

### Inside the Student's Card

When the teacher opens the student's card, the parent-owned fields show the parent's answers. The teacher can read the parent's comments, see their ratings, and review all the information the parent provided. The teacher can use this information to get a more complete picture of the student.

**What the teacher should do with parent observations:**
- Read the parent's comments and concerns.
- If the parent mentioned any issues (health concerns, family changes, etc.), the teacher should note them and follow up if needed.
- Use the parent's observations about the child's home behaviour to understand the child better.
- If the parent's observations contradict the teacher's observations, the teacher may want to have a conversation with the parent to understand the discrepancy.

## Common Questions from Teachers (FAQ)

### When should I generate a parent link?

You should generate a parent link AFTER you have finished filling the student's card and submitted it for review. Ideally, wait until the card is at least in "Finalised" or "Published" status. This way, when the parent submits their observations, the card is almost complete and ready.

However, if your school's workflow requires parent input before finalisation, you can generate the link earlier. Discuss the timing with your Principal.

### Can I send the link to both parents?

Yes. The system sends the email to the primary guardian's email address on file. If both parents have separate email addresses in the system, the school's admin can configure it to send to multiple addresses. Otherwise, the teacher can copy the link and send it to the second parent manually.

### What if the parent does not have internet access?

If the parent does not have internet access at home, the teacher can:
- Print the observation form (a paper version) and send it home with the student.
- The parent fills the paper form manually.
- The teacher enters the parent's responses into the system on their behalf.

This is not ideal, but it ensures that no parent is left out due to lack of internet access.

### Can I see which parent submitted the form?

If there are multiple guardians (e.g., mother and father), the email is sent to the primary guardian's address. The system logs which email address the link was sent to. If both parents have the same email address (shared), you cannot tell who filled the form. If they have different addresses, the link is associated with the specific email it was sent to.

### The parent says they submitted but I cannot see it. What happened?

Possible reasons:
- The parent may have clicked "Save" instead of "Submit". The form may still be "In Progress".
- There may be a technical issue. Ask the parent to try again with a new link.
- The parent may have clicked the link but not actually filled the form. Ask them to try again.

If the problem continues, generate a new link and ask the parent to try from a different device or browser.

### Can I edit the parent's responses?

No. The teacher cannot edit the parent's responses. Only the parent can fill their form. If a correction is needed, the teacher must generate a new link and ask the parent to resubmit.

### How do I know if the parent opened the email?

The system does not track whether the parent opened the email. It only tracks whether the email was successfully delivered (no bounce-back). If you want to confirm, you need to ask the parent directly.

### Can I resend the same link?

Yes. If the link has NOT expired (within 7 days) and the parent has NOT submitted yet, you can resend the same link. The link stays the same. You can find the link in the student's card and copy it again.

If the link has expired or the parent has already submitted, you MUST generate a NEW link.

### What if the wrong parent email is in the system?

Update the parent's email address in the school's main database (usually the Student Information System or ERP). Then generate a new link. The new link will be emailed to the updated address. The old link is automatically invalidated.

### Can I send bulk parent links?

Yes. Use the **Bulk Email** feature on the Student List screen. Select multiple students and click "Bulk Email". The system will send parent links to the guardians of all selected students. This is useful when you want to send links to all parents in your class at once.

### I do not have an email address. Can I still fill the form?
Yes. The teacher can print the link on a paper and give it to your child to bring home. You can type the link into a web browser on any device – a smartphone, a tablet, or a computer at the library or a neighbour's house.

You can ask the teacher to help you fill the form at the school. Many schools have computer labs or allow parents to visit and fill the form with the teacher's help.

### I am not comfortable with computers. Can someone help me?
Yes. You can ask your child's teacher to help you. You can also ask a family member or a neighbour who is comfortable with computers. The form is very simple – it is just like filling an online survey.

### I made a mistake after submitting. What do I do?
Contact your child's class teacher. They can generate a new link for you. You can fill the form again with the correct information. Your old submission will be replaced.

### The link is not working. What should I do?
The link may have expired (if more than 7 days have passed) or it may have already been used. Contact your child's teacher and ask for a new link.

### Is my information private?
Yes. Your responses are visible only to the school's teachers and authorised staff. They are stored securely in the school's database. Your information will not be shared publicly or with other parents.

### Can I see my child's grades and report card through this link?
No. The Parent Portal only shows the parent observation form. The teacher's assessments, grades, and other parts of the card are not visible through this link. After the card is published, you may receive a separate link to view the full card.

### Can I fill the form on my phone?
Yes. The form works on all devices – smartphones, tablets, laptops, and desktop computers. It automatically adjusts to fit your screen.

### Can I save the form and come back later?
Yes. The form has a "Save and Continue Later" feature. If you need to take a break, scroll to the bottom and click "Save". When you come back using the same link, you can continue where you left off. BUT remember – the link expires after 7 days, so do not wait too long.

### How long does it take to fill the form?
Most parents complete the form in 10 to 15 minutes. It has a few sections with simple questions. You do not need to write long answers.

## Current Status – What Is Built vs What Is Missing

**Important note for school administrators:** The Parent Portal screens and logic are built, but there is a missing piece that prevents the system from working. Here is the current status:

| Part | Is It Built? | What This Means |
|---|---|---|
| **Screen designs (views)** | ✅ Yes – Built | The Parent Dashboard, the observation form, the "Thank You" page, and the "Expired" page all exist. You can navigate to them. They look exactly as described in this document. |
| **Behind-the-scenes logic (controllers and services)** | ✅ Yes – Built | The code that generates the token link, sends the automatic email, and processes the form submission is all written and ready. |
| **Database table for storing tokens** | ❌ No – NOT Built | The database table that would store the parent tokens (the secret links) and the submitted parent data does NOT exist. The model file (the blueprint for the table) exists, but the database migration (the step that actually creates the table) has NOT been run. |

**What this means in practice:**
- You CAN see the parent portal screens and the form. They look fully built.
- BUT if a teacher tries to **generate a parent link**, the system will fail because there is no database table to store the token.
- Similarly, if a parent tries to **submit** the form, it will fail because there is nowhere to store the submitted data.

**Analogy:** The screens are like a ticket booth that has a window, a counter, a sign, and a printer – everything looks ready. But there are no actual tickets in the printer. The booth looks complete but cannot issue any tickets.

**What needs to happen:** A software developer needs to create and run the database migration. This is a technical step that creates the missing table in the school's database. Once that migration is run, the entire Parent Portal will work from start to finish – teachers will be able to generate links, parents will be able to fill and submit forms, and teachers will be able to see the results.

**Estimated developer effort:** This is a small task for a developer who knows the system. It involves running one command to create the database table. The developer does NOT need to write new screens or logic – just enable the missing database piece.
