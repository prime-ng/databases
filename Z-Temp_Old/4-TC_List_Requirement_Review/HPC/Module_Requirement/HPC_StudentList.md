# HPC Student List – Complete Guide for Teachers and Staff

**Who can use this screen:** Teachers (both class teachers and subject teachers), the Principal, Vice Principal, and School Administrators. You need to have been given the right HPC permissions by your school's system administrator. If you cannot see this screen, ask your admin to check your permissions.

**Where you find it:** This is the very first screen you see when you open the HPC module. Think of it as the home page or the starting point for all your HPC work. Every day, you will start here.

**What this screen does:** It shows a list of all the students in a selected class and section, along with the current status of each student's Holistic Progress Card. This is where you begin your work. You look at the list, find a student, and click a button to open their card, generate a PDF, send an email to the parent, or check the workflow status.

**Think of it like a control panel.** Each student is one row. Each column tells you something about that student or their card. The buttons on the right let you take actions.

---

## Step by Step – What a Teacher Sees When They Open HPC

Let us walk through what happens when you log in and open the HPC module for the first time today.

### Step 1: You See the Filter Bar at the Top

The top of the screen has three drop-down menus. These are called "filters" because they help you filter (narrow down) which students you want to see. Think of it like a sieve – you pour all the school's students in, and the filters let only the ones you want through.

### Step 2: You Select a Class

Click the first drop-down menu labelled "Class". A list of all the classes in your school drops down. Scroll through the list and click the class you want. For example, click "Class 5" or "5th".

**What happens after you select a class:** The second drop-down menu (Section) automatically updates. It now shows only the sections that belong to Class 5. If Class 5 has three sections – A, B, and C – those three options appear. The system does this automatically. You do NOT need to refresh the page or click any extra buttons.

**Why this matters:** If you selected a class first, the section list will only show valid sections. You cannot accidentally select a section that does not exist in that class. This prevents errors.

### Step 3: You Select a Section

Click the second drop-down menu labelled "Section". Select, for example, "A". 

**What happens after you select a section:** The table below refreshes automatically. It now shows only the students who are in Class 5, Section A. All other students disappear from the list. The table now shows, for example, 28 students – all the boys and girls in 5-A.

### Step 4: You Select the Academic Term

Click the third drop-down menu labelled "Academic Term". This lets you choose which term's cards you want to see. The options are typically:

- Term 1 (April to September)
- Term 2 (October to March)
- Final / Annual
- Any custom terms your school has set up

**Usually, the system pre-selects the current term for you.** For example, if the current month is November, the system automatically selects Term 2. But you can change it if you want to look at cards from a previous term.

### Step 5: The Student Table Updates

After you have selected Class, Section, and Term, the student table shows the matching students. Each row is one student. Each column gives you information about that student and their card.

| Column Name | What It Shows | Example |

| **Sl No / #** | A serial number. The first student in the list is 1, the second is 2, and so on. This is just for counting. | 1, 2, 3, 4 |

It tells you where the card is in its journey from empty form to final published card. See the detailed explanation below. | Draft, Submitted, Under Review, Finalised, Published, Archived |
| **Actions** | A set of buttons. Each button does something to this student's card. See the Action Buttons section below. | Open Card, Generate PDF, Send Email, View Workflow, Activity Assessment |

## Card Status – What Each Status Means (With Colours)

The Card Status column shows a coloured label. The colour helps you quickly see where each card is without reading the text. Here is what each status means, from start to finish:

| Status | Colour | What It Means | Can the Teacher Edit? | Can the Parent See It? |
|---|---|---|---|---|
| **Draft** | Blue | The card has been created but the teacher has not finished filling it in yet. Maybe they have only filled in half the fields. The card is still a "work in progress." Only the teacher who created it can see it. | Yes – the teacher can open the card and continue filling it. | No – parents cannot see a Draft card. |
| **Submitted** | Yellow / Orange | The teacher has finished filling the card and has clicked the "Submit" button. Now the card is waiting for someone to review it. It is like handing in a homework assignment. The teacher can no longer edit it. | No – the teacher cannot edit. It is locked. | No – not yet. |
| **Under Review** | Orange / Amber | Someone (usually the Principal or Vice Principal) is currently checking the card. They might leave comments or ask the teacher to fix something. The card is in the "review queue." | No – locked for editing. But the reviewer can send it back to Draft if changes are needed. | No – still not visible to parents. |
| **Finalised** | Green | The review is complete. The Principal has approved the card. Everything is correct. The card is ready but not yet published. This is like a teacher's final answer. | No – the card is locked. | No – parents cannot see it until it is Published. |
| **Published** | Purple | The card has been released. Parents and guardians can now see it through the Parent Portal. A link has been sent to them. The card is "live." | No – the card is final. | Yes – parents can view it. |
| **Archived** | Grey | The card is from a past academic year. It is kept as a historical record. Nobody can edit it anymore. It is stored for reference. | No – the card is locked permanently. | Yes – parents can still view old archived cards. |

**Why these statuses exist:** Imagine a teacher writes a report card on paper. First, they draft it in pencil (Draft). Then they finalise it in pen (Submitted). Then the Principal checks it (Under Review). The Principal approves it (Finalised). Then it is printed and sent home (Published). At the end of the year, it goes into the student's file (Archived). The statuses mirror this real-world process.

**What the colours mean at a glance:**
- **Blue** = Still being worked on
- **Yellow/Orange** = Waiting for someone else to act
- **Green** = Approved and ready
- **Purple** = Published and visible to parents
- **Grey** = Past and historical

## Action Buttons for Each Student

In the last column of the table, you see a set of buttons for each student. Here is a detailed explanation of what each button does.

### Open Card

**What it does:** Opens the teacher's data-entry card for that student. This is where you fill in all the assessment fields, marks, comments, attendance records, and anything else that the card contains.

**What happens when you click Open Card – step by step:**

1. The system looks at the student's grade level. For example, if the student is in Class 5, the system knows this student is in the "Preparatory" stage.
2. The system looks up the correct template for that stage. It finds the Preparatory template that the admin created in Template Management.
3. The system checks if this student already has a card for the selected term. If a card already exists (for example, the teacher started filling it last week and saved it as Draft), the system opens the existing card. You can continue where you left off.
4. If the student does NOT have a card yet, the system creates a brand new empty card. The status is set to Draft automatically. No separate "Create" step is needed.
5. The card opens as a multi-tab form. Each tab across the top is a "Part" that the admin configured in Template Management. Click each tab to see its sections and fields.

**Real-world example:**
> Mrs Sharma teaches Class 5-B. She logs in, selects Class 5, Section B, and Term 1. She sees student Aarav Patel in the list. The Card Status shows "Draft". She clicks "Open Card". The system sees Aarav is in Class 5 (Preparatory stage), opens the Preparatory template, and shows Aarav's partially filled card from last week. Mrs Sharma continues filling in the remaining fields. She saves her work and closes the card. Later, Aarav's status still shows "Draft" until she clicks "Submit".

**Important:** If the student does not have a card yet, clicking Open Card creates one automatically. You never need to click a "Create Card" button. Just click Open Card and the system handles everything.

### Generate PDF

**What it does:** Creates a print-ready PDF of the selected student's Holistic Progress Card and downloads it to your computer. The PDF looks exactly like the printed card would look. It includes all the fields, grades, comments, and the school's logo and branding.

**When you would use it:**
- You need a physical copy for a parent-teacher meeting.
- You want to print the card and file it in the student's physical record folder.
- You need to share a copy with another teacher who does not have computer access.
- You want to check how the card will look when printed before publishing it.

**What the PDF contains:**
- The student's name, class, section, roll number, and photo (if uploaded)
- All the grades, marks, and comments that the teacher has entered
- The school name, logo, and branding
- Page numbers
- The term name and academic year

**Technical note:** The PDF is generated on the server and sent to your browser as a download. Depending on your internet speed, it may take a few seconds. The PDF is not saved on the server – it is generated fresh each time.

### Send Email

**What it does:** Sends an email to the student's parent(s) or guardian(s). The email contains a secure link that the parent can click to view the card online. The parent does NOT need a login or password – the link itself is the access.

**What the parent receives in the email:**
- The school's name and branding at the top of the email
- The student's full name and class
- A sentence like: "Dear Parent, the Holistic Progress Card for your child is now available for viewing."
- A secure link that looks like: `https://school.edu/hpc/parent/view?token=abc123xyz789`
- An access code for extra security (if enabled)
- A note that the link will work for 30 days (or 7 days, depending on school policy)

**What happens if the guardian has no email address saved:**
The system simply skips that student and moves to the next one. It does NOT crash, freeze, or show an error. It logs a note: "Student skipped – no guardian email found." You will see a warning message after the process is complete.

**Important:** The email is sent from the school's email system. It will come from an address like `noreply@yourschool.edu`. Parents should check their Spam folder if they do not see the email in their Inbox.

### View Workflow

**What it does:** Opens a screen that shows you the complete history and current status of the card's review process. It is like looking at a tracking page for a package you ordered online – you can see every step the package has been through.

**What you will see on the workflow screen:**
- **Creation:** Who created the card and when. Example: "Created by Mrs Sharma on 15 Oct 2025 at 10:30 AM."
- **Edits:** Who edited the card and when. Example: "Edited by Mrs Sharma on 16 Oct 2025 at 2:15 PM."
- **Submission:** When the teacher submitted the card for review. Example: "Submitted by Mrs Sharma on 18 Oct 2025 at 11:00 AM."
- **Review Activity:** Who reviewed the card and what comment they left. Example: "Reviewed by Principal Singh on 19 Oct 2025 at 9:00 AM. Comment: 'Please update the attendance column for October.'"
- **Re-submission (if any):** If the reviewer sent the card back to Draft, you will see the re-submission.
- **Finalisation:** When the Principal approved the card. Example: "Finalised by Principal Singh on 20 Oct 2025 at 4:00 PM."
- **Publication:** When the card was published. Example: "Published by Principal Singh on 21 Oct 2025 at 8:00 AM."
- **Current Step:** Where the card is now. Example: "Waiting for Principal approval."

**When to use View Workflow:**
- You want to know if the Principal has seen the card yet.
- You want to see who last edited the card.
- You are troubleshooting why a card is stuck in a certain status.
- A parent called asking why they cannot see the card yet. You can check if it has been published.

### Activity Assessment

**What it does:** Opens the **Activity Assessment Overview** dashboard. This is a special screen that shows the completion status for ALL contributors on this student's card. Remember, the HPC is a multi-contributor system – the teacher, student, parent, and peers all contribute.

**What you see on the Activity Assessment dashboard:**

| Contributor | What It Shows | Example |
|---|---|---|
| **Teacher** | Have YOU filled in all your sections? What percentage is complete? | "85% complete – 3 out of 20 sections remaining." |
| **Student** | Has the student submitted their self-assessment? (Only for Middle and Secondary students) | "Student: Completed" or "Student: Pending" |
| **Parent** | Has the parent filled in their observation form through the Parent Portal? | "Parent: Submitted on 20 Oct 2025" or "Parent: Not yet started" or "Parent: Link expired – resend needed" |
| **Peers** | How many peer reviews have been completed? (Only for Middle and Secondary students) | "Peer reviews: 3 out of 5 completed" |

**When to use Activity Assessment:**
- Before finalising a card, you want to check: "Did the student finish their self-assessment?"
- You want to see if the parent has submitted their observations yet.
- You want to monitor how many peer reviews are still pending.
- You want a quick overview of what is done and what is still missing for a particular student.

## Bulk Action Buttons (Work with Multiple Students at Once)

At the top of the student table, there are buttons that work on MULTIPLE students at the same time. This saves you time when you need to do the same thing for many students.

**How to use bulk actions:**
1. Look at the leftmost column of the student table. Each row has a checkbox.
2. Click the checkbox next to each student you want to include. A checkmark appears.
3. If you want to select ALL students at once, click the checkbox in the header row (the top of the column). This selects every student in the list.
4. After you have selected the students, click one of the bulk action buttons below.

### Bulk Generation

**What it does:** Creates a PDF of the Holistic Progress Card for EVERY selected student, packages them all into a single ZIP file, and downloads the ZIP to your computer. You then open the ZIP file on your computer to access the individual PDFs.

**Why use it:** If you need printed cards for all 42 students in your class for a parent meeting tomorrow, you can generate all 42 PDFs with one click instead of clicking "Generate PDF" 42 times.

**Limits and rules:**
- You can select up to **50 students** at a time. This limit exists to keep the system fast and prevent it from getting overwhelmed.
- If you try to select more than 50 students, the system will show a message: "Bulk generation limited to 50 students. Please select fewer students."
- The ZIP file name is automatically generated and cleaned up – no spaces or special characters, only letters, numbers, underscores, hyphens, and dots. Example: `HPC_Class5A_Term1_2025-10-20.zip`
- Each PDF inside the ZIP is named after the student. Example: `Aarav_Patel_HPC.pdf`, `Priya_Sharma_HPC.pdf`

**Real-world example:**
> Mr Verma is the Class 10 class teacher. He needs printed cards for all 42 students in his class for the parent meeting tomorrow. He goes to the Student List screen, selects Class 10, Section A, and the current term. He clicks the checkbox in the header to select all 42 students. He clicks "Bulk Generation". The system processes the request and after a few seconds, a ZIP file downloads to his computer. He extracts the ZIP (right-click > Extract All) and now has 42 individual PDFs. He prints them all.

**What if some cards are not ready?**
The system generates PDFs for all selected students regardless of their status. Even Draft cards will produce a PDF. The PDF shows whatever data has been entered so far. Empty fields appear as blank spaces.

### Bulk Email

**What it does:** Sends the "view card" email to the guardians of EVERY selected student – all at once, without you having to click "Send Email" one by one for each student.

**How it works step by step:**
1. You select the students you want to send emails for.
2. You click "Bulk Email".
3. The system goes through each selected student, one by one.
4. For each student, it finds the guardian(s) and their email addresses from the school database.
5. It prepares the email with the secure link for that student.
6. It queues the emails to be sent in the background. This means you do NOT have to wait. You can continue working while the emails are being sent.
7. After all emails are queued, you see a summary message: "15 emails sent, 2 students skipped (no guardian email found)."

**Important notes about Bulk Email:**
- If a guardian has no email address saved in the system, that student is skipped. The system does NOT crash or stop – it just notes the skip and moves on.
- The emails are sent in the background (queued). You can continue working while the emails are being dispatched.
- If you accidentally click Bulk Email, do not worry. The system sends each parent only ONE email per card. If you click Bulk Email again, it will NOT send duplicate emails (the system tracks which links have already been sent).

## Summary – How a Teacher Uses This Screen Day to Day

Here is a typical day for Mrs Sharma, a Class 5 teacher:

1. **Morning (8:30 AM):** She logs in and opens HPC. She selects Class 5, Section B, Term 1. The student table shows 28 students. She scans the Card Status column. Five students show "Draft" (blue) – those are the ones she was working on yesterday.

2. **Fill in cards (9:00 AM – 11:00 AM):** She clicks "Open Card" for each of the five Draft students. She fills in the remaining fields, adds comments, and saves each card. For three students, she finishes completely and clicks "Submit". Their status changes to "Submitted" (yellow).

3. **Check progress (11:00 AM):** She looks at the Card Status column again. Two students are still in Draft – she needs to finish them tomorrow. 21 students are in "Finalised" (green) – the Principal approved them. The remaining students are in various stages.

4. **Send emails (11:30 AM):** She selects all students whose cards show "Published" (purple) by checking their checkboxes. She clicks "Bulk Email" to send card links to their parents. The system reports "15 emails sent, 1 student skipped (no guardian email)."

5. **Print cards (12:00 PM):** She needs printed copies for a parent meeting next week. She selects 10 students whose cards are Published. She clicks "Bulk Generation". A ZIP file downloads. She prints the PDFs.

6. **Monitor (2:00 PM):** She clicks "Activity Assessment" for a student whose parent called asking about the card. She sees the parent has not submitted their observation form yet. She generates a new parent link and emails it to the parent.

## Key Rules to Remember

1. **One card per student per term.** Each student can have at most one Holistic Progress Card for each academic term. You cannot accidentally create two cards for the same student in Term 1. If you try, the system simply opens the existing card.

2. **Template is chosen automatically.** You do NOT pick the template. The system looks at the student's grade level and automatically selects the correct template (Foundation, Preparatory, Middle, or Secondary). This happens in the background.

3. **No separate "Create" step.** If a student does not have a card yet, clicking "Open Card" automatically creates a new Draft card. You never need to find a "Create Card" button.

4. **Bulk Generation is capped at 50 students.** This keeps the system fast and responsive. If you need to generate PDFs for more than 50 students, do it in batches.

5. **Guardian email is required for email features.** The "Send Email" and "Bulk Email" features need the parent's email address to be saved in the school database. If the email is missing, the system skips that student and warns you.

6. **Status changes are one-way (mostly).** Once a card moves from Draft to Submitted, the teacher cannot edit it unless the reviewer sends it back. The teacher cannot un-submit a card. Similarly, once a card is Published, it cannot be unpublished (but an admin can archive it).

7. **The card is a multi-contributor document.** The teacher fills their part, the student fills their self-assessment (Middle and Secondary only), the parent fills their observation form, and peers contribute reviews. The teacher can monitor all of these from the Activity Assessment dashboard.

## Common Questions from Teachers (FAQ)

### What does the Card Status colour mean at a quick glance?

Remember this simple rule:
- **Blue** = Teacher is still working on it (Draft)
- **Yellow/Orange** = Someone else needs to do something (Submitted, Under Review)
- **Green** = Approved and ready (Finalised)
- **Purple** = Published – parents can see it
- **Grey** = Historical record (Archived)

### I cannot see the "Open Card" button. Why?

There are a few possible reasons:
- You do not have permission to open cards. Check with your school's system administrator.
- The student's card may have been archived. Archived cards show a grey status and you can only view them, not edit them.
- The academic term you selected may be closed. Some schools close terms after a certain date.
- The student may have transferred out of your class. Check with the school office.

### I clicked "Submit" by accident. Can I undo it?

No. Once you click Submit, the card is locked and sent for review. You cannot undo it yourself. You need to ask the Principal or the reviewer to "Send Back to Draft". They can do this from the review screen. This is intentional – it prevents teachers from changing answers after the review process has begun.

### Why is the "Generate PDF" button greyed out?

The Generate PDF button is always available for any card status. If it is greyed out, it may be:
- The card data is still being saved. Wait a few seconds and try again.
- There is a technical issue with PDF generation. Contact your school's IT support.
- The card may be completely empty with no data. Some systems require at least some data before generating a PDF.

### Why is the "Send Email" button greyed out?

This button may be greyed out because:
- The card has not been Published yet. Parents can only view published cards. The email feature is typically available only after the card is Published or Finalised.
- The student does not have a guardian email address saved in the system. The button will be disabled if there is no email to send to.
- The card is in Draft status. You need to submit and get the card approved before sending emails.

### How do I know if a parent has received the email?

The system does NOT track whether the parent opened the email. It only tracks whether the email was successfully sent (no bounce-back). If the email was sent successfully, the system logs it. If the email bounced (the address was wrong), the system shows a warning.

If you want to confirm that the parent received it, you can either:
- Ask the parent directly (phone call or in-person).
- Check the "Activity Assessment" dashboard to see if the parent has completed their observation form.

### Can I email multiple parents at once?

Yes. Use the **Bulk Email** feature. Select multiple students by checking their checkboxes, then click "Bulk Email". The system sends one email per student to their guardians. You can select up to 50 students at a time.

### The student list is showing students from a different class. What is wrong?

Check your filter settings at the top of the page. You may have selected the wrong Class, Section, or Term. Use the drop-down menus to correct your selection. The list refreshes automatically when you change any filter.

### Can I search for a specific student by name?

Yes. The student table has a search box at the top. Type the student's name (or part of the name) and the table will filter to show only matching students. This is useful when you have a large class and want to find a specific student quickly.

### What happens if a student moves to a different class mid-term?

If a student transfers to a different class mid-term, the following happens:
- The student's existing card (if any) stays with the old class. The old teacher can still access it.
- If the new class uses the SAME template, the new teacher can continue working on the same card.
- If the new class uses a DIFFERENT template (e.g., the student moved from Preparatory to Middle), a new card with the correct template is created. The old card is archived.

Talk to your school administrator if you have questions about how mid-term transfers are handled in your school.

### Can I delete a card?

You cannot delete a card from the Student List screen. Cards can only be deleted by an administrator from the backend system. However, you can:
- **Archive** a card (if you are an admin) – this removes it from the active list but keeps it for records.
- **Reset** a card – if a card was created by mistake, ask your administrator to reset it.

### Why is the "Activity Assessment" button showing zero completion for everyone?

This usually means that the student and parent portals are not yet fully set up. Remember from the current status notes:
- The Student Portal database tables are missing.
- The Parent Portal database tables are missing.

Until a developer runs the database migrations, the Activity Assessment dashboard will show zero completion for student and parent contributions because there is no database to store their submissions.

### I selected a student and clicked "Open Card" but it shows a blank page. Why?

This could be:
- The template for this student's grade has no Parts created yet. An admin needs to set up the template in Template Management.
- The student's card was corrupted. This is rare but can happen. Ask an administrator to check the card.
- Your browser needs a refresh. Press F5 or Ctrl+R to reload the page.

### How do I print cards in bulk?

Use the **Bulk Generation** feature. Select all students you want to print for, then click "Bulk Generation". The system will create a ZIP file containing individual PDFs for each student. Download the ZIP, extract it, and print the PDFs.

**Pro tip:** When printing many PDFs at once, use the "Print All" feature in your PDF viewer (like Adobe Reader) instead of opening each file individually. In Adobe Reader, you can select multiple PDF files, right-click, and choose "Print Selected Files".

### The system feels slow. What can I do?

- Try to avoid selecting all 50+ students for bulk operations during peak hours (9 AM – 11 AM when most teachers are working).
- Close other browser tabs that you are not using.
- Make sure your internet connection is stable.
- If the problem persists, contact your school's IT support team.
