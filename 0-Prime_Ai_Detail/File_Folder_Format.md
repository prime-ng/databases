# File's Name & Folder Structure Detail
=======================================

## Folder Structure for Test case Files
---------------------------------------
/prime_testing/tests/Browser/Modules/V2/{MODULE_NAME}/{SCREEN_NAME}/
E.g. - /prime_testing/tests/Browser/Modules/V2/Hpc/TemplateSections/

Then file for `TemplateSections` of `Hpc` Module will in this folder

## Test Case File's Format
--------------------------

Module Name  : Hpc
Screen Name  : TemplateSections
TC File Name : HpcTemplateSectionsTest.php
